# NOVA LAB

Uma experiência interativa e responsiva sobre criatividade, tecnologia e curiosidade. Projeto estático feito com HTML, CSS e JavaScript, sem etapa de compilação.

## Executar

Abra `index.html` no navegador. Para publicar, envie `index.html`, `style.css` e `script.js` para a mesma pasta no GitHub Pages ou em qualquer hospedagem de arquivos estáticos.

## Experimentos

- **Oráculo:** escreva uma pergunta e receba um convite para refletir.
- **Idea Engine:** selecione um tema e gere ideias de projetos.
- **Creative Mode:** alterne a paleta visual. A preferência fica salva no navegador.
- **Terminal:** use o botão no cabeçalho ou `Ctrl+K` (`⌘+K` no Mac). Comandos: `ajuda`, `ideia`, `oraculo`, `modo`, `sobre` e `limpar`.

O layout inclui navegação por teclado, estados de foco visíveis, suporte a movimento reduzido e adaptações para telas pequenas. As fontes do Google têm alternativas locais caso a conexão esteja indisponível.
